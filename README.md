# 100 Days of SwiftUI

My projects from Paul Hudson's [100 Days of SwiftUI](https://www.hackingwithswift.com/100/swiftui) course. I have a background in Swift and UIKit and use this course to learn SwiftUI.

## Projects

| Days | Project | What it does | What I practised |
|---|---|---|---|
| 16–18 | [WeSplit](WeSplit) | Splits a bill between several people and adds a tip | `Form`, `@State`, `@FocusState`, `Picker`, currency formatting |
| 19 | [Temperature Converter](Converter) | Converts temperatures between Celsius, Fahrenheit and Kelvin | Challenge day: segmented pickers, an enum for units, computed properties |
| 20–22 | [Guess the Flag](GuessTheFlag) | A game: tap the flag of the named country and keep score | `ZStack`, gradients, image buttons, alerts, game state |

## How to run

Open the `.xcodeproj` file in a project folder with Xcode 26.2 or later and run it in the iOS Simulator.
